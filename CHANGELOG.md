## [1.0.1]

### Release Date
2026-08-03

### This release includes
- Added customer tokenization support for faster repeat purchases
- Added optional Express Checkout for tokenized customers (disabled by default)
- Added admin tools to register, list, test, and delete Sezzle webhooks
- Added automatic Sezzle refund synchronization when Shopware transactions are marked as refunded
- Improved webhook processing reliability with signature validation and duplicate event protection
